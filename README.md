# Airport Management Information System

This project was developed for the Database Management Systems and Programming I course.

## Project Description
The Airport Management Information System is a relational database project designed for managing airport operations. The system stores and manages information about airplanes, employees, technicians, traffic controllers, hangars, aircraft tests, and maintenance operations.

## Features
- Plane management
- Plane model management
- Employee management
- Technician management
- Traffic controller management
- Hangar tracking system
- Hangar entry and exit records
- Aircraft testing system
- Technician expertise system
- Statistical SQL queries

## Technologies Used
- MySQL
- MySQL Workbench
- SQL
- GitHub

## Database Features
- Primary Keys
- Foreign Keys
- JOIN Operations
- GROUP BY Queries
- Aggregate Functions
- Relational Database Design
